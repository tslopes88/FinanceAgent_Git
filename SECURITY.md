# Politica de seguranca

## Reportando uma vulnerabilidade

Nao publique detalhes de vulnerabilidades em issues publicas. Envie uma descricao privada pelo recurso **Report a vulnerability** do GitHub ou entre em contato pelo perfil do autor:

- GitHub: https://github.com/tslopes88
- Projeto: informe o repositorio e a versao afetada

Inclua passos para reproduzir, impacto observado e uma sugestao de mitigacao quando possivel.

## Escopo

Este repositorio e um projeto de portfolio/desenvolvimento. Nao envie dados bancarios reais, credenciais, tokens ou documentos de clientes.
